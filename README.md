# skvwaffle manager
this simple website designed for fellow friends includes games, achievements, and chat along with a lot of customisability
## getting started
users must sign in before having access to the website. signing in means acknowledging and respecting the following documents:
 - CODE_OF_CONDUCT.md
 - CONTRIBUTING.md
 - LICENSE
## guide
below is a comprehensive guide of the many parts of the website
### main menu
this is where one starts off. it gives many places to continue one's journey throughout the website
### achievements & milestones
users may collect *achievements* via multiple different parts of the website. achievements are split into different namespaces and can be viewed in both List view
and Tree view. namespaces include:
 - **main**: includes the parts of the website which are not games. this includes the chat, blog, suggestions, polls, and settings.
 - **the others**: these achievements must be obtained by playing their specific game.
   
by collecting the different rarities of achievements (`common`, `rare`, `epic`, `legendary`, and `secret` in order), users will earn *points*. points unlock the various milestones. additionally, the Paragon systems rewards players for surpassing 2200 points.
### chat
the chat is a space where users may communicate with each other by means of text, GIFs (via the GIPHY API), and emojis. users must abide by the CODE OF CONDUCT at all times when in the chat. the chat also includes Smiley, an LLM powered by Qwen and a way to view other's profiles.
### settings
this is self-explanatory. users may change their theme, add custom profile pictures, cloak their tab to 3 presets, and view a selection of math ultilities.
### games
the games include:
 - **bulls and cows**: a game where players must guess the 4-digit code based on the "bulls" and "cows" of their previous guesses. includes 3 difficulties ranging from Easy to Hard and an algorithm to solve codes
 - **number pillars**: an original skvwaffle game. players must match the sum of each box to the target. levels increase in difficulty, eventually incorporating huge decimals. includes 3 difficulties ranging from Easy to Hard and a hints and experience system.
 - **chess**: the classic board game with analyses and the lichess opening database to identify thousands of openings.
 - **card games**: including blackjack and dou dizhu (鬥地主), players can play against bots or others. dou dizhu includes analyses.
 - **streetfighter**: an original skvwaffle game. in legacy mode (enabled via settings) players fight in real-time to gain Elo against bots. in turn-based mode, players create a lineup to battle bots.
games each have a rating system displayed on a users's profile. two achievements are linked to these rating systems.
### blog
the blog includes many community things, such as suggestions linked to the repo's Issues and a polling system. some major updates will be posted on the blog. users may post categorised suggestions
or create / vote in polls with up to 8 options. some achievements of the **main** namespace will require users to engage in these mechanics
### gacha
gacha is a way for players to gamble a currency *orbs* in exchange for a variety of *shards*. among those are **fragments**, which are far rarer.
