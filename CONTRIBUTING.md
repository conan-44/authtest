# Contributing Guidelines
contributors are free to:
 - change or add anything in the assets/ directory
 - add anything in the data/ directory
contributors may (with permission):
 - make minor changes or improvements to the repo in any directory
 - remove files
contributors may not:
 - make major changes in directories
## Disclaimer
though most changes will be rebased into the main branch and added into the website, contributors must understand before anything that
1. their changes may not necessarily be rebased
2. their changes may not add profanity or explicit content
